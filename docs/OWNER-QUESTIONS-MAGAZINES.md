# Questions for the owner: magazine pages, QR codes and offers

513 Auto Clean, November 11. About 10 minutes. Each question has a **recommended answer**: tick it, or write your own. With these answers, the two magazine pages, their QR codes and the tracking can be built straight away. Nothing here can be built correctly without them.

**What gets built once you answer:**
- **Two short pages,** one per magazine (for example 513autoclean.com/golf and /prestige). Each is written for that magazine's readers and ends in the booking form.
- **A QR code for each,** pointing at its page, as print-ready PNG and SVG files.
- **Tracking from scan to booking.** The site already notes which magazine sent a visitor and puts it in the booking email. Analytics adds scans and visits. "Where did you hear about us?" at checkout catches people who type the address or call.
- **A simple report per magazine:** visits, bookings and revenue, so you can see what each ad earned.

## The offer

**4. Should each magazine have its own offer?** An offer gives readers a reason to book now. A code unique to each magazine also counts bookings from people who never scan. Your current codes are LIKENEW (10% off) and FRIANDFAM (25%, friends and family).
- [ ] No offer, just the page
- [ ] 10% off, each with its own code (GOLF10, PRESTIGE10)
- [ ] A free extra with the first detail (which one? ________)
- [ ] A set amount off, e.g. $25 off a Full Interior
- [ ] Other: ________

*Recommended:* 10% off with a code for each magazine. It's simple, it matches LIKENEW, and it measures each ad even when nobody scans.

**5. Limits on the offer.**
- [ ] Ends on: ________
- [ ] First detail only, one per customer
- [ ] Works with the 10% multi-vehicle saving
- [ ] Never combines with another code (true today: one code per booking)

*Recommended:* ends 6 weeks after the issue lands, first detail only, one code per booking, and still works with the multi-vehicle saving.

**6. Should the magazine offer skip the rush fee?** (New.) In cold months, exterior and combined jobs can usually only be booked within the next week, which mostly falls inside the 3-day rush window. So readers who want an exterior detail would pay the 20% rush fee on top of the offer.
- [ ] Keep the rush fee as it is
- [ ] No rush fee on exterior bookings more than 1 day out (for everyone)
- [ ] No rush fee when the weather is what limits the dates
- [ ] Magazine codes skip the rush fee

*Recommended:* no rush fee on exterior bookings more than 1 day out. It's fair to every customer, not just magazine readers, and it stops winter exterior jobs from always costing 20% more.
